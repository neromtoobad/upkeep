I changed `src/cart.js` because js-cookie 3 no longer has `Cookies.getJSON`, and `Cookies.set` no longer turns objects into JSON on its own. The cart now saves its contents to the cookie with `JSON.stringify` and reads them back with `JSON.parse`. If the cookie is missing or can't be read, it falls back to an empty cart. Behaviour for the user stays the same, but I couldn't run the browser, so whether the three flows pass now depends on Upkeep's rebuild and Kane's next run.
